# Pulse

A Spotify-inspired music demo built with HTML, CSS, browser JavaScript, Node.js, Express, and MongoDB. It includes 12 original CC0 starter songs, artist uploads, a saved library, and a Database Mode view.

## Run

```bash
npm install
npm start
```

Open http://localhost:3000.

Create an account. Select **I want to upload music as an artist** if you want to upload audio. Any signed-in account can save songs to Liked Songs.

## Storage modes

The project currently uses `STORAGE_MODE=local` in `.env` because the configured MongoDB credentials were rejected. Local mode stores accounts, uploads, and saved songs in `data/store.json`; uploaded audio goes to `public/uploads/`. These paths and `.env` are ignored by Git.

To use MongoDB Atlas and inspect the same database in MongoDB Compass:

1. Replace `MONGO_URI` in `.env` with a working Atlas connection string. The Atlas database user and network access settings must permit a connection from this computer.
2. In Compass, create a connection using that same URI. The current URI selects the `spotify-clone` database.
3. Run `npm run migrate:local-to-mongo` to copy local accounts, uploads, and saved songs into MongoDB. The local JSON file is preserved.
4. Set `STORAGE_MODE=mongo` in `.env` and restart the server.
5. Open Database Mode in the app or refresh Compass. The `users` and `music` collections should be visible.

On successful connection, the server seeds the 12 starter track documents into the `music` collection. User accounts and saved track IDs are stored in the `users` collection. Artist uploads use ImageKit in MongoDB mode, so `IMAGEKIT_PRIVATE_KEY` must also be valid.

Database Mode reports the current backend and shows safe previews of the active collections. It never returns passwords or other users' account details.

## API

- `GET /api/music` — catalog and uploaded tracks
- `POST /api/auth/register`, `POST /api/auth/login`, `GET /api/auth/me`, `POST /api/auth/logout`
- `GET /api/library`, `PUT /api/library/:id` — saved songs for the signed-in user
- `POST /api/music` — artist audio upload
- `GET /api/database` — current storage mode and sanitized collection previews

The 12 bundled songs are generated by `npm run generate:music`. See `LICENSE-MUSIC.md`.
